## 🚀 Key Features
- 📚 **Course Catalog:** Interactive display of training programs and enrollment details.
- 🔐 **Authentication & Users:** Secure login/signup system powered by Supabase.
- 📱 **Fully Responsive:** Smooth UI experience across desktop, tablet, and mobile devices.
- ⚡ **High Performance:** Server-Side Rendering (SSR) for fast load times and better SEO.

## 📦 Main Dependencies
- `next`
- `react` / `react-dom`
- `@supabase/supabase-js`
- `tailwindcss`
- `lucide-react` (or icons library)

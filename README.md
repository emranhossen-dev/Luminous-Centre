# 🌟 Luminous Skills Training Center

The official web platform for **Luminous Skills**, a premier Skills Development Training Center. This project focuses on delivering a professional, high-performance educational experience for mentors and students alike.

**Live Link:** [luminous-centre.vercel.app](https://luminous-centre.vercel.app)

---

### 🚀 Project Vision
Luminous Skills is designed to bridge the gap between learning and professional success. The platform features a robust architecture to manage courses, mentors, and student progress with a focus on modern design and high-quality user experience.

### 🛠️ Technical Stack
- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS (Custom Dark Theme with #2F2FE4 & #080616 gradients)
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Deployment:** Vercel

---

### ✨ Key Features
- **Professional UI:** A high-contrast dark aesthetic designed for clarity and modern branding.
- **Role-Based Architecture:** Optimized workflows for Admins, Mentors, Employees, and Students.
- **Mobile-First Design:** Fully responsive layout with a custom-built navigation system.
- **Scalable Backend:** Powered by PostgreSQL and Prisma for secure and efficient data management.
- **Clean Code:** Adheres to "humanized" and beginner-friendly coding standards for long-term maintainability.
